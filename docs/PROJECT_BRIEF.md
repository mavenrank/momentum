# Momentum Project Brief

## Purpose

Momentum helps with planning, journaling, and accountability. The first version is
intentionally simple: it should make it easy to plan the day, zoom out for the
week, track flexible habits, and keep a daily note.

## Core Principles

- Solo-first, with accountability features planned for later.
- Local-first storage with a portable data file.
- Simple UI that feels like a practical planner, not a marketing site.
- Small, readable React components.
- No Tailwind CSS.
- Component-scoped CSS files instead of one large stylesheet.

## Initial Modes

- Daily: date-based tasks, categories, and top focus.
- Weekly: paper-planner inspired focus, priorities, follow-ups, day previews, and notes.
- Monthly: calendar overview with the top daily items visible at a glance.
- Habits: dynamic habits that can be created and checked from the app.
- Journal: daily writing entries.
- Data: export/import JSON for moving data between laptops.
