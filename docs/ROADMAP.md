# Momentum Roadmap

## v0.1.0 — Foundation (Current)
- [x] Project scaffold (React + Vite + TS + Bun)
- [x] Four views: Daily, Weekly, Monthly, Goals & Habits
- [x] Weekly planner spread (3-column layout)
- [x] Dynamic habit CRUD
- [x] localStorage persistence
- [x] JSON export / import for portability
- [x] Daily journal / notes
- [x] Color-coded tasks and scheduling grid

## v0.2.0 — Polish & Analytics
- [ ] Habit streak tracking & calendar heatmap
- [ ] Weekly reflection prompts
- [ ] Task categories / tags
- [ ] Search across tasks and notes
- [ ] Dark mode
- [ ] Keyboard shortcuts (n, j/k, etc.)
- [ ] Responsive / mobile-friendly layout

## v0.3.0 — Accountability (Solo+)
- [ ] User profiles (local-first)
- [ ] Generate a shareable read-only link of your planner
- [ ] Friend can view your weekly/daily spread via link
- [ ] Optional: gentle nags / reminders (browser notifications)

## v0.4.0 — Buddy System
- [ ] Friend management (add/remove)
- [ ] Side-by-side view: see friend's planner alongside yours
- [ ] Accountability check-ins (did you do your habits?)
- [ ] Comments / reactions on friend's weekly focus

## v1.0.0 — Stable
- [ ] Full test coverage
- [ ] i18n-ready
- [ ] PWA (installable, offline)
- [ ] Performance audit
- [ ] Accessibility audit

## Future Considerations (Unversioned)
- Switch to Next.js for SSR / better routing
- Backend: SQLite via Turso or similar (multi-device sync)
- Mobile app (React Native or Flutter)
- API for third-party integrations
- Calendar sync (Google Calendar, CalDAV)
- Dual remote: push to both Codeberg and GitHub
