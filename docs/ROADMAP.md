# Roadmap

## Phase 1: Solo Planner

- Daily planner with categorized tasks, top focus, satisfying completion, and journal.
- Weekly planner for broader focus, priority buckets, follow-ups, and notes.
- Monthly overview for scanning the top daily planner items.
- Dynamic habit tracking.
- Local storage with JSON import/export.

## Phase 2: Better Portability

- File-based sync workflow using a small JSON file.
- Conflict handling for importing newer or older planner data.
- Optional encrypted backup export.

## Phase 3: Accountability Buddy

- Share read-only planner summaries with a friend.
- Track friend check-ins.
- Add accountability prompts and weekly review summaries.

## Phase 4: Multi-Device Future

- Evaluate backend options only after the local-first app feels solid.
- Possible candidates: SQLite-backed desktop wrapper, Supabase, or a small custom API.
- Consider Next.js only if routing, server features, or auth become important.
