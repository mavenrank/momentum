# Momentum

A personal planner for weekly planning, daily journaling, habit tracking, and goal accountability.

## Getting Started

```bash
bun install
bun dev
```

## Data Portability

Export your data from Settings → Export to download a JSON file. Import on another device to transfer all data.

## Tech

React 19, Vite 8, TypeScript 6, Zustand, date-fns, Bun.
