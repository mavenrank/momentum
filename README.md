# Momentum

Momentum is a lightweight planning and journaling app for personal accountability.

It starts as a solo planner with local-first data, portable JSON backups, daily tasks,
weekly intention setting, dynamic habits, and daily notes. Future phases can add
friend/accountability views without changing the core app shape.

## Stack

- Bun package manager
- React
- TypeScript
- Vite
- Plain CSS by component area

## Commands

```bash
bun install
bun run dev
bun run build
```

## Current Modes

- Daily: dynamic task capture, categorized priorities, and focus.
- Weekly: paper-planner inspired focus, priority buckets, day previews, and notes.
- Monthly: compact calendar overview with top daily planner items.
- Habits: dynamic weekly habit tracker.
- Journal: daily writing archive.
- Data: JSON export/import for portable local data.

## Versioning

The current version is stored in `VERSION.txt`. Changes are tracked in
`CHANGELOG.txt` using Semantic Versioning.
